# notes/

Agent working records. These files are kept permanently and committed.

- `<ID>.md`: builder handoff note (template: `templates/handoff.md`)
- `<ID>/`: evidence artifacts for a ticket (screenshots, PDFs, logs)
- `<ID>.review.md`: reviewer verdict, with a Round 2 section if re-reviewed
  (template: `templates/review.md`)
- `gate-<N>.md`: milestone gate report (template: `templates/gate.md`)
- `gate-<N>/`: gate demo evidence
